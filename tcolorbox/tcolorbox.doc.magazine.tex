\begin{tcolorbox}[

这是一篇示例文章，从这里开始，
并延续到后续各页。
文章正文写在一个单独的 |tcolorbox| 里。
本框利用本节的工具被拆成若干片段，
具体使用了 \refKey{/tcb/reset and store to box array}，
配合一个新的盒子数组 |myarticle|——
该数组由 |\newboxarray{myarticle}| 创建。

拆出的各片段则用 \refCom{consumetcboxarray}
分放到本 \zvref{sec:magazine} 的适当位置（即你所见之处）。
像\emph{见第 x 页}这样的衔接文字，
是由外层 \refCom{tcbox} 的 \refKey{/tcb/finish} 命令生成的。
为给各片段加标签，使用了 \refKey{/tcb/phantomlabel}。

这些很小的片段框仅作演示之用。
借助本节的工具，固然可以做出杂志式文档，
但仍需大量手动控制。
\end{tcolorbox}

\begin{articleside}[after skip=6pt]
本程序库的主要用途，是把一个 |tcolorbox| 存入一个盒子寄存器数组，
以备日后使用。

若 |tcolorbox| 不可断开，
则相较通常的 \TeX/\LaTeX\ 盒子存取并没有太多额外之处
（这种情况下你其实并不需要本程序库）。
对于可断开的 |tcolorbox|，本程序库能把所有片段框
捕获到一串寄存器中。这些片段框可在任意位置、按任意顺序使用。
\tcblower\consumetcboxarray[myarticle]{1}{blanker,nobeforeafter,phantomlabel=myarticle-one,goto=two}
\end{articleside}

本程序库之名\emph{magazine}既取"存储"之义，
也取"杂志"之义——在杂志里一篇文章常常\emph{转到第 x 页}继续。
此类应用的一个示例贯穿本节，从右侧开始。
本程序库的创建由 Ulrike Fischer 与 Steven B.~Segletes 促成。

该程序库通过宏包选项或在导言区中用以下方式加载：
\begin{dispListing}
\tcbuselibrary{magazine}
\end{dispListing}
这还会加载 \mylib{breakable} 程序库，参见 \zvref{sec:breakable}。

\begin{marker}
本程序库的盒子寄存器操作是全局的。退出当前 \TeX\ 分组时，
不会清除这些寄存器。还要注意：大量使用大型盒子数组
可能会耗尽 \TeX\ 可用的内存与寄存器。
\end{marker}

\subsection{盒子数组的创建与重置}\label{subsec:magazine_creation}

\begin{docCommand}[doc new=2015-07-13]{newboxarray}{\marg{name}}
  创建一个名为 \meta{name} 的新盒子数组。已有一个名为 |default| 的
  盒子数组可直接使用。注意：创建是一个全局操作。
\begin{dispListing}
\newboxarray{myarray}
\end{dispListing}
\end{docCommand}


\begin{docCommand}[doc new=2015-07-13]{boxarrayreset}{\oarg{name}}
  将盒子数组 \meta{name} 的大小计数器重置为零。
  若未给出 \meta{name}，则使用 |default|。
  在使用 \refKey{/tcb/store to box array} 之前，
  应先使用本命令或 \refKey{/tcb/reset box array}。
  否则，新盒子会被追加到已有盒子之后。
  本命令不会清除盒子寄存器。
\begin{dispListing}
\boxarrayreset            % resets `default'
\boxarrayreset{myarray}   % resets `myarray'
\end{dispListing}
\end{docCommand}

\enlargethispage*{20mm}

\begin{docTcbKey}[][doc new=2015-07-13]{reset box array}{\colOpt{=\meta{name}}}{默认 |default|，初始未设置}
  将盒子数组 \meta{name} 的大小计数器重置为零。
  在使用 \refKey{/tcb/store to box array} 之前，
  应先使用本选项或 \refCom{boxarrayreset}（二者作用相同）。
\begin{dispListing}
\tcbset{
  reset box array,         % resets `default'
  reset box array=myarray, % resets `myarray'
}
\end{dispListing}
\end{docTcbKey}

\clearpage
\begin{docCommand}[doc new=2015-07-13]{boxarrayclear}{\oarg{name}}
  与 \refCom{boxarrayreset} 一样将盒子数组 \meta{name} 的大小计数器重置为零。
  此外，还会清空该盒子数组所分配的全部盒子寄存器的内容。
  注意：已分配的寄存器仍保持分配状态。因此，这有助于释放内存，
  但不能把寄存器腾给其他用途。若此前已用 \refCom{consumeboxarray}
  或 \refCom{consumetcboxarray} 取用了所存盒子，
  则再用 \refCom{boxarrayclear} 并无额外好处。
\begin{dispListing}
\boxarrayclear            % clears `default'
\boxarrayclear[myarray]   % clears `myarray'
\end{dispListing}
\end{docCommand}



\subsection{存储内容}\label{subsec:magazine_storing}

\begin{docTcbKey}[][doc new=2015-07-13]{store to box array}{\colOpt{=\meta{name}}}{默认 |default|，初始未设置}
将一个 |tcolorbox|，或一个 |tcolorbox| 断开序列的所有片段，
存入盒子数组 \meta{name}。若未给出 \meta{name}，
则使用已有的 |default| 盒子数组；否则必须事先用
\refCom{newboxarray} 创建该数组。注意：若希望文本框断成数段，
则该框必须是 \refKey{/tcb/breakable} 的。
通常还需用 \refKey{/tcb/break at} 手动指定断开点；
否则各片段长度约为 |\textheight|。
对大多数用法，应先使用 \refKey{/tcb/reset box array}
以重置盒子数组计数器。\enlargethispage*{2cm}

\begin{exdispExample}{storetoboxarray_1}
% \usepackage{lipsum}
\begin{tcolorbox}[enhanced jigsaw,size=fbox,width=4cm,
  colback=yellow!10,colframe=yellow!10!black,
  enforce breakable,% use only breakable in the real world!
  break at=7cm/4cm,
  height fixed for=all,
  watermark text=\arabic{tcbbreakpart},
  reset box array,
  store to box array
  ]
\lipsum[1]
\end{tcolorbox}

\useboxarray{1}\hfill
\begin{tabular}[b]{cc}
\multicolumn{2}{c}{\includegraphics[width=7cm]{Basilica_5.png}}\\
\useboxarray{2} & \useboxarray{3}
\end{tabular}
\end{exdispExample}

\clearpage

可在 \refKey{/tcb/break at} 的第一项使用

你可能还希望它与前文之间留出一些额外间距。

\begin{docEnvironment}[doc new=2015-07-13]{boxarraystore}{\marg{name}}
  将本环境的内容存入盒子数组 \meta{name}。
  这相当于标准 \LaTeX\ 环境 |lrbox|，但存储操作是全局的。
  只要不使用 \refCom{boxarrayreset}，每新开一个 \refEnv{boxarraystore}
  就会向数组再追加一个盒子。

\begin{dispExample}
\boxarrayreset
\begin{boxarraystore}{default}\fbox{Mary}\end{boxarraystore}
\begin{boxarraystore}{default}\fbox{Had}\end{boxarraystore}
\begin{boxarraystore}{default}\fbox{a}\end{boxarraystore}
\begin{boxarraystore}{default}\fbox{Little}\end{boxarraystore}
\begin{boxarraystore}{default}\fbox{Lamb}\end{boxarraystore}
\useboxarray{5}\useboxarray{4}\useboxarray{3}\useboxarray{2}\useboxarray{1}\hfill
\useboxarray{1}\useboxarray{5}
\end{dispExample}
\end{docEnvironment}

\subsection{取用内容}\label{subsec:magazine_retrieve}

\begin{docCommand}[doc new=2015-07-13]{boxarraygetsize}{\oarg{name}\marg{macro}}
\begin{articleside}[before skip=5pt]
  将盒子数组 \meta{name} 的当前大小存入给定的 \meta{macro}。
  若未给出 \meta{name}，则使用已有的 |default| 盒子数组。
\begin{dispExample}
\boxarraygetsize{\mysize}
Current size of the default box array:
\mysize.
\end{dispExample}
\tcblower\consumetcboxarray[myarticle]{2}{blanker,nobeforeafter,phantomlabel=myarticle-two,from=one,goto=three}
\end{articleside}
\end{docCommand}

\begin{docCommand}[doc new=2015-07-13]{useboxarray}{\oarg{name}\marg{index}}
  排版输出盒子数组 \meta{name} 中编号为 \meta{index} 的盒子。
  若未给出 \meta{name}，则使用已有的 |default| 盒子数组。
  若使用了不存在的盒子数组 \meta{name}，视为错误。
  若 \meta{index} 越界，则被静默忽略。
  注意：\refCom{useboxarray} 对应标准宏 |\usebox|，
  即 |\copy|。
\begin{dispExample}
\boxarraygetsize{\mysize}
\foreach \n in  {1,...,\mysize} { \useboxarray{\n} }
\end{dispExample}
\end{docCommand}

\clearpage
\begin{docCommand}[doc new=2015-07-13]{usetcboxarray}{\oarg{name}\marg{index}\marg{options}}
  取盒子数组 \meta{name} 中编号为 \meta{index} 的盒子，
  用 \refCom{useboxarray} 作为 \refCom{tcbox} 的内容进行排版。
  若未给出 \meta{name}，则使用已有的 |default| 盒子数组。
  若使用了不存在的盒子数组 \meta{name}，视为错误。
  若 \meta{index} 越界，则被静默忽略。
  可用 |tcolorbox| \meta{options} 定制该 \refCom{tcbox}。
\begin{dispExample}
\boxarraygetsize{\mysize}
\foreach \n in  {1,...,\mysize} { \usetcboxarray{\n}{on line,colframe=yellow,
  colback=yellow!10} }
\end{dispExample}
\end{docCommand}


\begin{docCommand}[doc new=2015-07-13]{consumeboxarray}{\oarg{name}\marg{index}}
  排版输出盒子数组 \meta{name} 中编号为 \meta{index} 的盒子。
  若未给出 \meta{name}，则使用已有的 |default| 盒子数组。
  若使用了不存在的盒子数组 \meta{name}，视为错误。
  若 \meta{index} 越界，则被静默忽略。
  与 \refCom{useboxarray} 不同，
  \refCom{consumeboxarray} 对应标准宏 |\box|，即排版后该盒子寄存器
  被清空，不能再次使用。
\begin{dispExample}
\boxarraygetsize{\mysize}
First run: \foreach \n in  {1,...,\mysize} { \consumeboxarray{\n} }
\par
Second run: \foreach \n in  {1,...,\mysize} { \consumeboxarray{\n} }
\end{dispExample}
\end{docCommand}

\begin{docCommand}[doc new=2015-07-13]{boxarraygetbox}{\oarg{name}\marg{macro}\marg{index}}
  将盒子数组 \meta{name} 中编号为 \meta{index} 的盒子
